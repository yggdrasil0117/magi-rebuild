# MAGI 当前使用指南

更新：2026-11-01。

适用：Windows、Python 3.12、本机单用户、千问云端模型。先使用原生网页完成主流程，Open WebUI和终端是可选入口。

## 1. 启动

在项目目录打开PowerShell。已有`.venv-harness`时直接运行：

```powershell
.\scripts\start_magi.ps1
```

启动时可能分别要求输入千问API Key和硅基流动API Key：隐藏输入，仅传给当前进程。千问负责生成，硅基流动BGE-M3负责已启用的向量检索。随后窗口会显示**本机服务凭据**，复制它用于网页连接。这些凭据用途不同：模型API Key用于调用千问，本机服务凭据用于访问自己的MAGI后端；不要把模型API Key填进网页。

打开[本机聊天页](http://127.0.0.1:8765)，展开“设置”，粘贴本机服务凭据并点击“连接”。默认会话可以直接使用，不需要先填写计划ID、版本号或预算。刷新页面后凭据为空，需要重新连接。

关闭服务：在启动窗口按Ctrl+C。先不要关闭窗口中的错误信息；启动或生成失败时保留错误码，方便定位。不要同时启动多个worker或reload。

首次安装环境时运行以下命令，已有环境不必每次重装：

```powershell
python --version
python -m venv .venv-harness
.\.venv-harness\Scripts\python.exe -m pip install -r requirements-qianwen.lock.txt
.\.venv-harness\Scripts\python.exe -m pip install --no-deps -e .
.\scripts\start_magi.ps1
```

要求Python 3.12。锁文件包含harness、Web和千问适配依赖；不需要为了运行云端模型下载Ollama。脚本策略受限时可用：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\start_magi.ps1
```

## 2. 走完一条主流程

1. **日常交流**：默认“三人格分析：关闭”，直接发送问题。普通聊天可查询资料或已有计划，不一定形成计划。
2. **重要取舍**：开启“三人格分析”，说明目标、约束、未知项及完成条件。展开回复中的讨论详情可看三个真实观点。若有硬性总时间预算，可在设置→开发者选项填分钟；程序不会可靠地从任意自然语言自动抽取全部硬约束。
3. **确认保存**：核对候选的步骤、假设、未知项后，点击“确认保存此候选”。生成成功不是保存成功；正式结果在“我的计划”中可查。
4. **查看与恢复**：打开“我的计划”选中标题，切换版本查看。停止并重启服务后，使用同一数据目录仍可查询，不需要重新生成计划。
5. **执行反馈**：在计划详情点击“对最新版提交反馈”，填写实际发生的变化。系统基于读取时最新版提出修订候选；再次确认才新增版本，原版本保留。开始反馈后可修改预算，或点击“退出修订”。
6. **执行材料**：在已保存版本中“准备任务工作单”，核对后批准或拒绝。批准才创建Markdown文件，输出位置在页面显示。文件只是执行材料，不代表学习或采购等事项已经完成。

工作单拒绝后不能批准原预览；需要时准备新工作单。重复核对已创建文件不会新建或覆盖用户编辑。批准已保存但执行中断时，只在明确重试时恢复；BLOCKED表示需要核对实际文件或重新准备，启动和GET不会自动执行。

## 3. 记忆和资料

自动记忆建议可以在设置中暂停。候选只有经用户确认才成为有效长期记忆；忽略记录也会保留，不等于会话结束删除。个人记忆可在页面管理，修改会影响有效上下文和旧候选。

资料搜索只在配置的`[tools].root`授权目录中读取UTF-8 Markdown/TXT/RST。返回原文路径和行号，但有预算和大小限制；搜索覆盖不完整或没结果不代表所有资料没有答案。不是互联网搜索，也不是已经建好的向量知识库。

## 4. 成功与失败怎么判断

- 模型回答、候选、正式计划、工作单文件是不同对象；以真实保存记录、版本和文件核对结果为准。
- PARTIAL或FAILED不代表完整审议，不会提供可保存的完整候选；保留失败事实后，可新发更清楚的请求，不会自动重试。
- 发送断线时，再点发送会重试同一消息编号，避免重复生成；“取消这次发送”只放弃客户端重试，不撤销服务器已经完成的操作。
- 背景或计划版本变化可能使候选过期，需重新生成。旧版本仍可读取，不代表仍适用于当前情况。
- 模型仍可能误解要求、遗漏条件或提出不合适建议；结构检查通过和流程完成都不是内容正确的保证。

当前没有完整账号登录、多人隔离、任意终端执行或通用自主行动能力。Open WebUI与终端的交互适配范围见各自文档，工作单完整批准/拒绝入口以原生网页为准。

## 5. 数据与验收

默认业务数据和checkpoint在`.magi`目录，以`magi.qianwen.toml`为准。审批checkpoint与业务库同目录，备份时一起保留；不要为了重试清空数据。历史显示、推理checkpoint和已确认业务记录职责不同。

本轮产品范围和验证状态见[MVP交付清单](MAGI_MVP交付清单.md)及第24轮总结。开发验收使用独立数据，不能把演示目录当正式个人数据。

离线检查：

```powershell
.\.venv-harness\Scripts\python.exe -m pytest -q
```

早期的`verify_web_mvp.py`及旧截图对应旧版界面，不能直接当当前页面验收说明；当前原生网页流程以本指南及第24轮证据为准。


## 授权资料的云端向量检索

当前magi.qianwen.toml的`[embedding]`已明确启用BGE-M3，环境变量为SILICONFLOW_API_KEY，与千问DASHSCOPE_API_KEY分开提供。启动脚本会隐藏询问缺失值，不自动读取或保存个人凭据文件；网页仍只填本机服务凭据。

开启三人格时，程序将授权tools.root范围内、预算允许的原文片段和问题送给硅基流动生成向量，再将相似候选冻结给三人格。页面“本轮参考资料”可查看原文和版本；向量失败会明确标记退回关键词。无结果不等于资料没有答案，相似度不等于事实正确。

如不使用云端向量，把`[embedding].enabled=false`。该选项不关闭千问生成；两者用途不同。现阶段最多前128块参与向量检索、返回前5条，缓存保存于业务库同目录retrieval.db；修改文件会产生新版本向量，旧计划原文保留。向量缓存及资料索引不代表正式计划已保存，仍要点击确认。

更新后若页面仍显示旧来源标签，可Ctrl+F5强制刷新，然后重新填写本机服务凭据连接。详细代码、固定案例、误召回及验证限制见[模块029](MAGI_模块总结_029_硅基流动BGE_M3向量检索.md)。

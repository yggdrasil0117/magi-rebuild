# MAGI 模块总结 012：计划查看、版本对比与反馈入口

日期：2026-10-30。按用户要求优先完善最小 MVP，内容质量问题继续记录，最终决策由用户确认。

## 1. 本轮完成什么

原生网页新增“已保存计划”区域：刷新列表后点击计划即可读取正文，不必复制计划 ID；可以选择历史版本，并排查看两版正文及文本增删差异。只有一个版本时提示暂不可对比。

“对最新版提交反馈”会重新读取服务器最新版、选择三人格模式并填写修订目标和基准版本。它只准备输入，**不会直接调用模型或保存计划**。填写反馈并发送后得到新候选，仍需点击确认保存。

确认成功后自动刷新列表并打开保存结果；退出修订或切回日常模式会清除旧目标、版本及时间预算，避免误带入下一次普通聊天。断线重试仍复用原消息，切换修订目标前需先处理或放弃该重试。

## 2. 调用链与边界

```text
刷新列表 → GET /v1/plans
选中计划 → GET /v1/plans/{id} + /versions
对比版本 → GET /v1/plans/{id}/compare?from_version=1&to_version=2
提交反馈入口 → 重新GET最新版 → 填写修订目标
发送反馈 → 原有审议接口 → 待确认候选
确认保存 → 原有事务、幂等与版本冲突检查 → 新版本
```

新增的版本目录与对比接口均需凭据，仅从 SQLite 读取，不调用模型、不写计划。目录只加载版本元信息，正文按需读取。对比包括标题和正文，展示的是文本变化，不是模型评价或自动合并。

`plan_id` 始终表示同一份计划，v1/v2/v3 是不可变版本。反馈提交的 `expected_version` 表示它基于哪一版；另一个请求若先更新，后端仍拒绝过时写入。界面读取最新版不能替代后端并发校验。

前端通过请求序号忽略旧计划选择的迟到响应，版本选择改变后隐藏过时对比。正文和标题使用 `textContent` 显示。新增脚本单独放在 `app.js`，包含中文函数说明，随 HTML 一起打包。

## 3. 验证总结

最终全套：**277 passed，18.05秒**；一个已有 Starlette/AnyIO 弃用警告。四个变更 Python 文件 Ruff 检查、格式检查通过，`node --check` 验证前端语法通过。

API集成测试覆盖：目录与对比鉴权、版本排序、目录不加载正文、双版本及相同版本对比、非法版本422、不存在版本/计划404、背景变化标记，以及读取不调用模型、不增加版本。

使用 Playwright CLI 操作真实 Edge，连接真实 FastAPI 和独立 SQLite，模型与 checkpoint 为桩，没有调用千问或本地模型。验证流程：

1. 打开已有两份计划的列表，查看学习计划v2，比较v1/v2的正文和增删差异。
2. 切到v1详情，点击反馈，页面明确以服务器最新版v2为基准。
3. 发送反馈生成候选，数据库仍为v2，操作总数仍为3。
4. 确认后生成v3，操作总数变为4；重复确认仍为v3、4次操作。
5. 停止API进程，再用同一数据库启动新进程；刷新页面需重新填写凭据，未认证时明确提示401；随后可读取v1/v2/v3及对比。
6. 单版本计划禁用对比；日常模式清空修订目标、版本及预算。
7. 390像素窄屏下对比列纵向排列，无横向溢出；桌面、反馈和窄屏截图均已查看。

首次浏览器加载发现 favicon 404，补充空 favicon 后刷新不再请求缺失图标。测试过程中页面变化导致旧元素引用失效，重新获取快照后继续，不把工具引用失效当作产品故障。受控401会产生预期浏览器网络错误日志。

本地wheel隔离构建成功，并检查包含 `magi/web/index.html` 和 `magi/web/app.js`。首次非隔离构建因主环境缺少 setuptools 失败；隔离构建解决工具依赖问题，未升级运行依赖。

## 4. 复现离线页面

新增 `scripts/serve_plan_demo.py` 只用于独立模拟验收，不是产品启动入口。它预置两份演示计划、使用真实保存与版本逻辑，模型和checkpoint为桩。选择一个独立目录和未占用端口，在当前终端设置临时 `MAGI_API_TOKEN` 后运行：

```powershell
.\.venv-harness\Scripts\python.exe -X utf8 scripts/serve_plan_demo.py --data-dir .magi/plan-demo --port 8876
```

打开 `http://127.0.0.1:8876` 并填写该临时凭据。服务只绑定本机；不要把演示数据目录设为真实业务目录。日常产品入口仍为 `scripts/start_magi.ps1`。

浏览器验收使用专用会话和测试凭据，未读取云端密钥。原始截图、CLI快照及测试数据库保存在忽略目录；导出只有非敏感验证材料。专用浏览器和两次API进程均已关闭。此次未新增真实模型或Open WebUI验收。

## 5. 典型问题记录与限制

仓库根目录新增 [question.md](../question.md)，归档引用、超时、通用性、语义、幂等版本和静态资源打包六类问题。后续典型问题继续记录；每项包含证据、取舍、改动、验证和限制，供学习与简历整理。AGENTS.md同步加入该约定以及最小MVP优先原则。

当前限制：

- 历史聊天文字保留生成时“尚未保存”的表述；保存事实以已保存计划详情和回执为准。本轮没有重写旧聊天记录或实现持久保存徽标。
- 当前仍是单用户本机界面，无计划删除、分页、全文搜索和手动编辑器。
- 背景变化会显示需复核；反馈入口不会绕过现有epoch与版本边界，过时背景的计划仍可能被后端拒绝修订。
- 页面中的“读取时最新版”不是实时订阅，外部修改后需刷新。模型内容质量与网络超时仍沿用前轮限制。

本轮完成后先等待用户阅读复述。后续优先整理最小MVP演示与使用验收，按实际使用反馈决定下一项改进，不因内容歧义无限扩展本轮范围。

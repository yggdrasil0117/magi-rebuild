# 设计决策006：有界资料关键词检索

日期：2026-10-31。第21轮先补设计，再实现。

依据v0.2第10节“先有界文件与关键词搜索”，为日常助手新增`magi_search_files(query, path)`只读工具。它在配置的授权资料根目录内检索Markdown、TXT、RST；返回相对路径、行号、原文片段、文件字节SHA-256及覆盖范围说明。默认从`.`开始，模型可指定更小子目录。

首版采用区分大小写的字面子串匹配，不执行正则、shell、网络、嵌入或持久索引。查询长度最多80字，拒绝空白及多行查询。逐次扫描有固定条目、文件、总读取字节和结果数量预算；预算导致提前停止，或符合类型的资料因大小、编码、权限被跳过时，标记覆盖不完整。隐藏命名、链接和不支持类型属于明确排除范围，单独计数，不将其算作支持范围内的漏读。无结果不等于授权目录没有答案。摘要是本次读取快照，资料后续变化需重新检索；原文定位不等于语义正确或文档当前适用。

不跟随目录或文件符号链接/Windows目录联接，不返回授权目录之外的路径；跳过隐藏项与常见依赖目录，UTF-8解码失败、大文件、权限错误分别计数。模型只传查询词与相对目录，不得修改预算、路径权限或写入参数。

接入现有function calling白名单与调用预算，不改变计划、候选、记忆或context_epoch，不开放文件创建。模型应按实际片段给出来源路径和行号，覆盖不完整或无结果时明确说明，可缩小目录、换词或读取已知文件。结果中的文档内容是资料，不是新的执行授权。

本轮先让日常助手可检索；不把检索结果自动登记为三人格独立证据，也不新建上传、解析、向量知识库或另一套Yggdrasil。记录离线边界、真实模型调用和浏览器工具流程，固定评测保留全部尝试，不把少量通过当作普遍准确率。
